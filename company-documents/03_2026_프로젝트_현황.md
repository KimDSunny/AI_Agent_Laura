# 2026 프로젝트 현황

## Laura Onboarding Agent v1.0

- 목적: 신입사원의 회사 이해, 온보딩 진행, 일정 등록을 하나의 대화에서 처리한다.
- 현재 단계: 2026년 9월 사내 QA와 디자인 파트너 5개사 파일럿 준비
- 이번 마일스톤: 9월 25일까지 RAG 답변 정확도 평가와 Calendar 승인 흐름 안정화
- 다음 마일스톤: 9월 28일 고객 파일럿 시작, 11월 2일 v1.0 정식 출시
- 성공 기준: 근거 있는 답변 비율 95% 이상, 온보딩 담당자의 반복 문의 30% 감소
- 주관: 개발팀 박도현, 기획팀 김서윤
- 진행 순서: 사내 QA → 고객 파일럿 → 안정화 → 정식 출시

## Orbit Workspace Admin

- 목적: 입사자의 계정 발급, 필수 문서, 교육, 체크리스트, 결재 상태를 한 화면에서 관리한다.
- 현재 단계: 핵심 화면 프로토타입과 HRIS·SSO 연동 요구사항 정의
- 이번 마일스톤: 10월 9일까지 관리자 프로토타입 사용성 테스트
- 다음 마일스톤: 12월 디자인 파트너 대상 비공개 베타
- 성공 기준: 입사 준비 업무 처리 시간 40% 단축
- 주관: 기획팀 김서윤, 디자인팀 이나경

## Compass People Analytics

- 목적: 온보딩 이탈 구간과 반복 질문을 익명·집계 데이터로 분석한다.
- 현재 단계: 문제 정의와 개인정보 영향 검토
- 이번 마일스톤: 10월 16일까지 지표 사전과 데이터 최소 수집 원칙 확정
- 다음 마일스톤: 12월 내부 분석 프로토타입 검증
- 성공 기준: 개인 평가에 사용하지 않고 팀 단위 개선 인사이트를 제공할 것
- 주관: 기획팀 김서윤, 인사팀 정유진
